# 1. 前言

Markdown是一种轻量级标记语言，它允许人们使用易读易写的纯文本格式编写文档，然后转换成格式丰富的HTML页面。

&nbsp;
# 2. 标题

Markdown支持6级标题，使用`#`符号表示，数量代表标题级别。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
```

&nbsp;
# 3. 段落和换行

## 3.1. 段落

段落由一个或多个连续的文本行组成，段落之间用一个或多个空行分隔，无论使用多少的空行，渲染结果只有一行。

```markdown
这是第一个段落。

这是第二个段落。
```

这是第一个段落。

这是第二个段落。

这是第一个段落。
