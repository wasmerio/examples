## General questions

### Do I need to have prior experience before proceeding with the Clarity theme?

**Yes.** You'll need to be familiar with Hugo before proceeding.
[Our docs section]({{< ref "/docs/_index.md" >}} "Clarity theme documentation") is intended for intermediate to
advanced users and developers. Our documentation may still be helpful to users with minimal experience, but are not
comprehensive.

### Do I need to use the extended version of Hugo?

**No.** Clarity theme intentionally does not use any features of the extended version. As such, the extended version of
Hugo is not required (but applicable).
