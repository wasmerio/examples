## Deploy on Wasmer

This folder is the [Agency Theme](https://github.com/vbartalis/agency-template) Astro theme by vbartalis, copied from commit `19f362e236a8488c4c7ba5199ba3bdd0d4be2dd2` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-agency-vbartalis.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with npm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Resized 6 images over 300 KB to at most 1600 px wide, keeping file names and formats.
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [vbartalis](https://github.com/vbartalis), NOASSERTION. The theme's license file is kept unchanged.
