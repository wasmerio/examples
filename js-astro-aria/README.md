## Deploy on Wasmer

This folder is the [Aria](https://github.com/ccbikai/astro-aria) Astro theme by ccbikai, copied from commit `1cbef9e8c87f88c88992ae2574e4ecbca4baa971` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-aria.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with pnpm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - None. The theme builds as published.
- **Environment variables:** None.
- **Credit:** theme by [ccbikai](https://github.com/ccbikai), Apache-2.0. The theme's license file is kept unchanged.

# Aria Template

This is a personal blog, portfolio, or blog template created for [Astro](https://astro.build).

Astro port of [aria](https://github.com/static-templates/aria).

![Aria Template Cover Photo](https://github.com/ccbikai/astro-aria/blob/main/public/assets/images/cover.png?raw=true)

You can install this theme with the [Astro](https://astro.build) command like so:

```js
npm create astro@latest -- --template ccbikai/astro-aria
```
