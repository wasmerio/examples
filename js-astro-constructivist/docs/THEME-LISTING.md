## Short description

A constructivist Astro portfolio with layered loading, modular navigation,
chapter-driven motion, six palettes, printable CVs, and single-file configuration.

## Full description

Constructa brings the visual language of editorial posters to a usable portfolio:
oversized interleaved typography, diagonal planes, precise rules, and a shared
original geometric mark. Color plates assemble into the entrance, independent
navigation tiles guide the document, and seven short chapter bridges carry that
identity through the page. Local scroll timelines connect biography, experience, work, skills,
and contact; the desktop work chapter becomes a horizontal exhibition without
locking the entire page into a screen stage.

Personalize content, navigation, copy, SEO, palette, and feature settings in one
schema-backed `cv.json`. The theme ships with a searchable command index, project
case dialogs, gallery modes, a compact printable CV, and a seeded SVG/PNG poster
studio. Reduced-motion and no-JS content remain readable, and small screens keep
a natural document flow. Built with static Astro and browser TypeScript, with no
React islands or application server required.

## Feature bullets

- Distinct constructivist identity: oversized type, paper/ink contrasts, diagonal geometry.
- Seeded interleaved hero typography and an independently implemented pixel globe.
- Configurable color-plate entrance with a skip control and bounded font readiness.
- A shared original mark, chapter-specific bridges, and an editorial full-screen menu.
- Section-local GSAP motion with a progressive horizontal project exhibition.
- One `cv.json` for content, copy, navigation, SEO, palette, and feature settings.
- Six palettes with dark variants and storage-safe preference controls.
- Searchable `Cmd/Ctrl + K` index, project cases, gallery modes, and keyboard controls.
- Independent navigation tiles with active-section, hover, and focus feedback.
- Reduced-motion, natural mobile layouts, no-JS content, and semantic sections.
- Compact CV printing, A4 poster composition, and downloadable SVG/PNG posters.
- Static Astro output and GitHub Pages repository-base support; no React runtime.

## Submission route

Astro's [theme submission link](https://astro.build/themes/submit/) leads to the
[Astro Dev Portal](https://portal.astro.build/themes/submit). The public page
requires GitHub sign-in; the current built-in browser is signed in to the

The maintainer should review the current criteria and terms, and submit
only after the public demo and release are ready. Preparing this document does
not submit a theme, grant an endorsement, or make it an official Astro theme.

## Claims to avoid

- Awwwards awards, nominations, or affiliations not actually earned by this theme.
- Lighthouse scores, performance rankings, or browser coverage not measured on the release.
- Accessibility certification or support for every browser and assistive technology.
- “Zero JavaScript”: the output is static, but interactive enhancements ship browser scripts.
- React Bits component redistribution or a claim that all dependencies are MIT licensed.
- “Listed on Astro” until the directory listing has actually been accepted and published.
