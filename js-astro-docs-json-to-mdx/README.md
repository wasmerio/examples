## Deploy on Wasmer

This folder is the [Docs Json To Mdx](https://github.com/reliverse/astro-docs-json-to-mdx) Astro theme by reliverse, copied from commit `a76e4085b0dfedeae7c53dd18162d6ab493eeeef` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-docs-json-to-mdx.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with bun, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [reliverse](https://github.com/reliverse), MIT. The theme's license file is kept unchanged.
