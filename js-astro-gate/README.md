## Deploy on Wasmer

This folder is the [Gate](https://github.com/sarasate/gate) Astro theme by sarasate, copied from commit `bbe4fb224ede6852410253a0fac690ca59d2238e` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-gate.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with npm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [sarasate](https://github.com/sarasate), MIT. The theme's license file is kept unchanged.

# Gate

Static API documentation with Astro and OpenAPI/Swagger.

## Usage

Currently, just import your OpenAPI JSON file in the main `index.astro` file as a default `data` import.
