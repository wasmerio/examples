## Deploy on Wasmer

This folder is the [Gd4 Ark Github Io](https://github.com/gd4Ark/gd4Ark.github.io) Astro theme by gd4Ark, copied from commit `4da149233eb63fc3ba802c22083b552c33c9dc5e` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-gd4-ark-github-io.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with pnpm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [gd4Ark](https://github.com/gd4Ark), MIT. The theme's license file is kept unchanged.
