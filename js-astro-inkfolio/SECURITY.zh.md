# 安全策略

## 报告漏洞

不要开公开 issue。请用本仓库的 GitHub 私密漏洞报告，或作者站点上列出的邮箱。请说明受影响的文件或地址、攻击者能拿到什么、你做了什么；有最小复现更好，没有也能报。

几个工作日内会回复。这是一个人的项目：修好才发，不为了快而发。

## 范围

在范围内：主题自己的代码——模板、组件、`scripts/` 工具链、发到浏览器的内联脚本，以及文档里写明的配置面。

不在范围内：托管商、DNS、你自己 fork 的内容或密钥，以及需要改动读者机器的攻击。

## 这套主题刻意为之的事

- 运行时不加载第三方 JavaScript。字体与图标本地打包。统计默认是无 cookie 的 Umami；GA4 与 Clarity 只在同意之后加载。
- 天气部件不需要 API key：定位用免 key 查询，请求由浏览器发起。若配置 `geoEndpoint`，请把它放在服务端。
- 仓库里不该有密钥。配置是 YAML，敏感值放托管平台的环境变量。

## 支持范围

只维护 `main` 上的最新状态，旧 tag 不再打补丁。
