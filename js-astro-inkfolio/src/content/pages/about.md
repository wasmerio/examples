This is the About page. It lives in `src/content/pages/about.md` — open that file, replace these paragraphs with your own, save, and the page updates.

Inkfolio ships with the bare minimum: a home page with your latest posts, a posts index, article pages, and this About page. There is no tag archive, no pagination and no comment system, because most personal sites do not need them and every extra page is something else to maintain.

If you keep the language switcher on, write the Chinese version in `src/content/pages/about-zh.md`. Leave that file alone and the `/zh/about/` page will just show whatever is in it — so either translate it or hide the link from `site.config.yaml`.
