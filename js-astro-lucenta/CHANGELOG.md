# Changelog

All notable changes to Lucenta are documented here.

## 1.0.0 - 2026-11-18

- Initial release.
- Astro 7 theme for design studios and agencies with home, work, case study, services, studio, journal, category archive, entry, contact, privacy, terms, RSS, robots, sitemap, and 404 routes.
- Work, people, and journal collections that reference each other, validated at build time.
- Hero headline with a capsule of cycling project images, and a full-bleed reel that grows from a card as it scrolls in.
- Full-width featured case-study cards on the homepage.
- Case studies painted in each project's own colour, with a parallax cover, stills, results, credits and a next project link.
- Shared-element page transitions from a project card into its case study.
- Work index with discipline filters and a list view whose rows flood with the project colour.
- A manifesto that lights up word by word, counters, a velocity-driven client marquee, and a cursor-following image over lists.
- Services page with deliverables and related work, and a studio page with team, process, recognition and clients.
- Journal with categories, pagination, reading time, related work, RSS and a share card.
- Contact page with a project enquiry form, live studio clocks and an FAQ.
- A solid header that takes its tone and colour from what sits under it, and a full-screen mobile menu.
- Self-hosted Epilogue and Mona Sans.
