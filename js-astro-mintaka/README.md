## Deploy on Wasmer

This folder is the [Mintaka](https://github.com/majesticooss/mintaka) Astro theme by majesticooss, copied from commit `b4ca4c291d5e30740ddd3a9f769a70b2e3ed3273` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-mintaka.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with bun, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [majesticooss](https://github.com/majesticooss), Unlicense. The theme's license file is kept unchanged.
