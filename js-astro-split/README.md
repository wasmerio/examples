## Deploy on Wasmer

This folder is the [Split](https://github.com/advanced-astro/split) Astro theme by advanced-astro, copied from commit `ec75726d64278f8307cbcb16cad4d308c8b599c0` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-split.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with pnpm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Removed files used only by other hosts: vercel.json.
  - Resized 1 image over 300 KB to at most 1600 px wide, keeping file names and formats.
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [advanced-astro](https://github.com/advanced-astro), MIT. The theme's license file is kept unchanged.
