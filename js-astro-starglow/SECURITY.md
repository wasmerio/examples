# Security policy

starglow builds a static site, so most issues are in the build tooling, the
GitHub workflows or the small amount of client JavaScript it ships.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/glowing-space/starglow/security/advisories/new).

You can expect a first reply within a week. Once a fix is released, the
advisory is published with credit to you, unless you prefer otherwise.
