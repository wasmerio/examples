## Deploy on Wasmer

This folder is the [Stylus](https://github.com/nanarino/stylus) Astro theme by nanarino, copied from commit `e6db248ed344cfe1072e86b811a14d216c93e0e7` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-stylus.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with pnpm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Dropped 3 video, audio or font files that nothing in the theme references.
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [nanarino](https://github.com/nanarino), MIT. The theme's license file is kept unchanged.
