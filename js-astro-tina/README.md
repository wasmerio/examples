## Deploy on Wasmer

This folder is the [Tina](https://github.com/chrismwilliams/astro-tina) Astro theme by chrismwilliams, copied from commit `2bafb8c8f95586134385d70bdae4d52eda6029a5` so it can be deployed as a Wasmer Edge template.

- **Demo:** https://astro-tina.wasmer.app
- **Deploy:** open the template on [wasmer.io/templates](https://wasmer.io/templates) and click **Deploy**, or run `wasmer deploy` in this folder. Wasmer installs with pnpm, runs the build script with Node 24 and serves the static `dist/` folder.
- **Changed for Wasmer:**
  - Added .nvmrc with Node 24, the Node version Wasmer builds with.
- **Environment variables:** None.
- **Credit:** theme by [chrismwilliams](https://github.com/chrismwilliams), MIT. The theme's license file is kept unchanged.
