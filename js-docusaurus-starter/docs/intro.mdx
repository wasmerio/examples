# Your documentation

This starter builds a static Docusaurus site and serves it on Wasmer Edge.

## Run locally

```bash
npm install
npm start
```

## Add a page

Create a Markdown file in `docs/`. The sidebar discovers it automatically.
Use [Docusaurus components](https://docusaurus.io/docs/markdown-features) to add tabs, notices and code blocks.

## Build and deploy

```bash
npm run build
```

Commit your source and deploy it from Wasmer. Anybuild builds this directory and serves `build/`.
Set the production `url` in `docusaurus.config.ts` to your app's actual URL before publishing.
